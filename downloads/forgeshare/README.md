# ForgeShare Mac test · 0.1.18

Download: [ForgeShare-mac-0.1.18-test.zip](ForgeShare-mac-0.1.18-test.zip).

Unverified test build for macOS. It is not Developer ID signed or notarized. It can require manual user approval; no automatic sharing occurs merely by downloading it. Use at your own risk and back up wikis. Node.js is required for the TiddlyWiki server. Tailscale is optional for local-only use. Private sharing over the owner's Tailscale VPN was tested on Mac/iPad; public Funnel is not confirmed. Windows is not offered while Microsoft Defender's previous Wacatac alert remains unresolved.
