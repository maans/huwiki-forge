# Editions

Hver Edition har et manifest med relative stier til JSON-tiddlere og TiddlyWiki-pluginbundles. `demo` er den første, afgrænsede test.

Alle Editions indlæser `../shared/libraries.json` fra deres manifest. Det giver den fælles adresse til **HUWiki Plugin Library** samt en **HUWiki Community**-side i TiddlyWikis sidebjælke. Plugins kommer fra Forge via GitHub Pages; Community viser offentlige Editions og evt. frivilligt offentliggjorte wiki-links.
