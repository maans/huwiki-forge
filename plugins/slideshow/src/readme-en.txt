! HUWiki Slideshow

[[Explore the seven stories|HUWiki Slideshow – Start]] and make your own version. The workshop can also start with individual tiddlers, a tag, open tiddlers or a saved title list.

* Slides stay connected to their tiddlers. Drag them into order and add private speaker notes.
* Design uses the existing PasteUp plugin. Change the whole presentation or individual slides.
* Import reads local documents. PDF can become page images or editable text. DOCX/PPTX/ODT/ODP have local text readers; visual Office import can use an optional [[local LibreOffice helper|https://github.com/maans/huwiki-forge/tree/main/tools/slideshow-converter]].
* Export offers PDF, an editable presentation package, an interactive HTML site and a backup of the whole wiki. Embed external media first.
* Save the whole wiki with TiddlyWiki’s Save button. The workshop’s automatic save updates the open wiki; it does not automatically write to disk.

Select Danish/English in TiddlyWiki’s control panel. Original example text and your own content are not changed by switching language.

Import limit: 20 MB and 150 slides/sections. Office animations and speaker notes are not imported through PDF. Scanned PDF pages can be viewed as images; OCR is not included. Desktop Chrome has been tested; mobile/touch acceptance is pending.

Original sources, authors and vendor licenses are retained. [[Sources and limitations|https://github.com/maans/huwiki-forge/blob/main/docs/creative-editions.md]].
