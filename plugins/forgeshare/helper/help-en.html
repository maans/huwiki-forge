ForgeShare · Help

Find. Open. Share.

Your wikis stay on your computer. You choose when other people can access them.

Find your wikis

ForgeShare finds wikis in Wikis, Documents, Desktop and Downloads. Choose one from the list. Use Add if it is missing. Discovery does not start sharing.

Open or share

Select a wiki or site and press Share. Use Stop on its library row to stop that wiki or site. The status light shows whether it is running. HTML wikis are prepared automatically. Choose sharing for each wiki or site on its first start. That choice is remembered only for that item. Under Settings → Sharing settings, select an item to change its sharing. Running wikis keep running. Open opens one wiki locally. Save and close an HTML wiki before sharing; after verified conversion, the original moves to Trash. The library keeps just the prepared wiki. You can still export HTML for offline use.

Send the right link

Under Active wikis, choose Copy address and send it to your guests. With Tailscale, they also need Tailscale access. For home sharing, they need to be on the same network. This computer and ForgeShare must keep running. Stop ends only the selected wiki.

Funnel — share over the internet

Choose Sharing → Funnel, then Share for your wiki. Choose one reader code and a different editor code. Guests open the link from Copy address and enter only their code; they do not need Tailscale. Open in the helper gives you editing access. Codes apply to the whole wiki. Give editor access only to people you trust. Codes are requested at each start and never saved. Login lasts up to eight hours and ends when sharing stops. Open /_forgeshare/login at the wiki address to use another code.

Funnel needs HTTPS and Funnel permission in Tailscale. It supports only 443, 8443 or 10000. ForgeShare selects a free port and never replaces existing services. If all three are occupied, Funnel cannot start on this computer until one is freed. Tailscale sharing is private; a Funnel address is public and protected by the codes. Repeated login attempts are limited. Choose codes that are not easy to guess. Automatic Funnel startup is not included in this version.

Save an overview in a wiki

Choose Export, then check the wikis and sites to include. Use Select all / Select none to change the whole selection. Optionally include shared addresses and name the overview. Drag the saved file into your wiki, review it and choose Import. This copies names and details, not wiki contents. File paths and passwords are never included. Reuse the overview name when exporting again; use another name for a different library.

Start automatically

Keep the app in a permanent location. Choose Settings → Start at login. You can also select a wiki to start when the app opens. Disable startup in the same place. This runs after you log in to your computer. Funnel is still started manually.

Changes arrive slowly

The wiki checks the server periodically. $:/config/SyncPollingInterval sets that interval in milliseconds. 3000 means three seconds; reload the page on each device after changing it. An image does not necessarily open its own tiddler automatically: search for its name. Check that both devices use the same wiki address and that saving succeeds.

Backups and simultaneous edits

Back up the whole wiki folder regularly, preferably after stopping its server. Tailscale provides a connection, not backups. Avoid editing the same tiddler at the same time: the last save can overwrite someone else’s changes. Comments stored in separate tiddlers reduce this risk. A library export is only an overview, not a backup of wiki content.

If something goes wrong

Check that the host computer is awake, the wiki appears under Active wikis and the address is correct. With Tailscale, check sign-in, invitations and HTTPS setup. If an address is occupied, ForgeShare stops instead of replacing another service. Close and reopen the app if a dialog gets stuck. This does not delete your wiki.

Why does the browser say “Not secure”?

Home network sharing uses an http://192.168.… address or another private network address. The browser warns because it does not use HTTPS. Tailscale sharing provides an https://…ts.net address with HTTPS. Use that address from the helper for the encrypted Tailscale connection. A wiki login alone does not encrypt HTTP.

AI and the vault

Choose Connections → Open vault → Add AI connection. Select your service and save its address, model and optional key. The key stays on this computer.

In the wiki, choose Connect to ForgeShare. Compare its code with the request under Approve a device in the vault. Select exactly which connections and wiki names it may use. Access can be revoked and expires after 30 days. People you approve can spend from your API account.

Open the wiki through the helper and install the updated AI plugin. This version supports text chat with LM Studio, Ollama, OpenAI and compatible servers. Images through the vault are not supported yet. Other stored passwords can be selected as an AI connection credential; they are never shown in a wiki.

Wiki overview without imports

Open ForgeShare → Open your wiki library in the wiki. Connect and approve the device as above. Refresh overview fetches permitted names, descriptions and last-known sharing addresses directly from the helper. Export remains available for an offline copy.

Share an HTML site

Choose Add → HTML site and the folder containing index.html. Select it in the library and press Share. The helper serves the page and its assets directly. Visitors can read, but cannot change the files. Choose a folder containing only the site you want to share.

Invite by email

Under Sharing, press Invite. Add a comment. The link is included; a saved sharing code is included only if you choose it. Your mail app opens a draft. You select recipients and send it yourself.

Close the window or quit?

On Mac and Windows, ForgeShare keeps running when you close its window. Reopen it from the menu-bar or tray icon. Choose Quit ForgeShare to stop the app and its sharing sessions. On Linux, closing the status dialog stops that session.

Tailscale and devices

Settings → Open Tailscale opens the Tailscale app. Connections → Tailscale devices lists peers visible to Tailscale. These are not necessarily wiki visitors. Approve AI access separately in the vault.
