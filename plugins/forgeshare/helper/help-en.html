ForgeShare · Help

Find. Open. Share.

Your wikis stay on your computer. You choose when other people can access them.

Find your wikis

ForgeShare finds wikis in Wikis, Documents, Desktop and Downloads. Choose one from the list. Use Add if it is missing. Discovery does not start sharing.

Open or share

Select one or more wikis and press Share. HTML wikis are prepared automatically. Settings under Sharing are remembered; the default is Tailscale without additional wiki login. Running wikis keep running. Open opens one wiki locally. Save and close an HTML wiki before sharing; after verified conversion, the original moves to Trash. The library keeps just the prepared wiki. You can still export HTML for offline use.

Send the right link

Under Active wikis, choose Copy address and send it to your guests. With Tailscale, they also need Tailscale access. For home sharing, they need to be on the same network. This computer and ForgeShare must keep running. Stop ends only the selected wiki.

Who can use the wiki?

Choose with or without wiki login. Without login, everyone with access to the chosen network can read and edit. Home network connections are unencrypted. Use Tailscale access rules to limit guests to the chosen wiki rather than the entire computer. Separate reader and editor roles are not included in this version.

Save an overview in a wiki

Select the wikis to include and choose Export selected. Optionally include shared addresses and name the overview. Drag the saved file into your wiki, review it and choose Import. This copies names and details, not wiki contents. File paths and passwords are never included. Reuse the overview name when exporting again; use another name for a different library.

Start automatically

Choose Startup in ForgeShare, then a wiki and its access. It starts the next time the app opens. With wiki login enabled, you are asked for the username and password; they are not stored. Choose Startup → Only open the library to turn it off.

To also open the app at login:

  • Mac: Put the app in Applications. In System Settings → General → Login Items & Extensions, add ForgeShare to Open at Login.
  • Windows: Keep all extracted ZIP files together in a permanent folder. Press Windows+R, enter shell:startup, and place a shortcut to ForgeShare.exe in that folder. This opens a folder, not a terminal.
  • Linux: Use your desktop’s Startup Applications settings and choose Start-ForgeShare.sh. The setting’s name varies by desktop.
This runs after you log in, not before anyone logs in. Remove the app from the system startup list to undo it.

Changes arrive slowly

The wiki checks the server periodically. $:/config/SyncPollingInterval sets that interval in milliseconds. 3000 means three seconds; reload the page on each device after changing it. An image does not necessarily open its own tiddler automatically: search for its name. Check that both devices use the same wiki address and that saving succeeds.

Backups and simultaneous edits

Back up the whole wiki folder regularly, preferably after stopping its server. Tailscale provides a connection, not backups. Avoid editing the same tiddler at the same time: the last save can overwrite someone else’s changes. Comments stored in separate tiddlers reduce this risk. A library export is only an overview, not a backup of wiki content.

If something goes wrong

Check that the host computer is awake, the wiki appears under Active wikis and the address is correct. With Tailscale, check sign-in, invitations and HTTPS setup. If an address is occupied, ForgeShare stops instead of replacing another service. Close and reopen the app if a dialog gets stuck. This does not delete your wiki.

Why does the browser say “Not secure”?

Home network sharing uses an http://192.168.… address or another private network address. The browser warns because it does not use HTTPS. Tailscale sharing provides an https://…ts.net address with HTTPS. Use that address from the helper for the encrypted Tailscale connection. A wiki login alone does not encrypt HTTP.
