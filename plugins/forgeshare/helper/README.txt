DANSK

Mac-pakken er kun til teknisk afprøvning. Den er endnu ikke en almindelig,
signeret app, og macOS kan blokere den. Den er ikke klar til uøvede brugere.

1. Pak hele ZIP-filen ud i en mappe, f.eks. på skrivebordet.
   Lad filerne blive sammen.
2. På Mac: dobbeltklik på Start-ForgeShare.command.
   På Windows: dobbeltklik på Start-ForgeShare.cmd.
   På Linux: åbn Start-ForgeShare.sh. Vælg om nødvendigt at tillade kørsel
   i filens egenskaber. Dialogboksene kræver programmet Zenity.
3. Følg dialogboksene. Vælg en gemt wiki efter navn, eller tilføj en
   forberedt wikimappe. Vælg login, og bekræft delingen til sidst.
4. Kopiér adressen fra statusvinduet, og åbn den i din browser.
   Lad vinduet stå åbent. OK eller Annuller stopper kun den wiki.
   Åbn startfilen igen for at dele endnu en wiki samtidig.

Du skal ikke skrive kommandoer i Terminal. Et terminalvindue kan stå
bag dialogboksene; det må gerne blive der, mens du bruger hjælperen.

Node.js og Tailscale skal være installeret på computeren:
https://nodejs.org/en/download
https://tailscale.com/download

En almindelig HTML-wiki skal først klargøres til deling. Se “Første
opsætning” i wikiens ForgeShare-vejledning; få eventuelt hjælp hertil.
Bevar din oprindelige HTML-fil som kopi.

Hvis Mac siger, at Apple ikke kan kontrollere filen for malware, så stop
afprøvningen. Det er et problem med udgivelsen af denne testhjælper.
Ny udpakning og ændrede kørselsrettigheder løser ikke den sikkerhedskontrol.
Du skal ikke skrive kommandoer eller slå computerens beskyttelse fra.
Læs eventuelt Apples forklaring: https://support.apple.com/en-us/102445

De inviterede skal have Tailscale. Før du inviterer nogen, skal adgangen
være begrænset til den ønskede wiki. Se “Del med en person eller en gruppe”
i ForgeShare. Tag backup, og undgå at redigere samme artikel samtidig.

ENGLISH

The Mac package is for technical testing only. It is not yet an ordinary
signed app, and macOS may block it. It is not ready for nontechnical users.

1. Extract the entire ZIP into one folder, for example on your desktop.
   Keep the files together.
2. Mac: double-click Start-ForgeShare.command.
   Windows: double-click Start-ForgeShare.cmd.
   Linux: open Start-ForgeShare.sh. If needed, allow it to run in the
   file's properties. The dialogs require the Zenity application.
3. Follow the dialogs. Choose a saved wiki by name or add a prepared
   wiki folder. Choose a login, then confirm sharing at the final step.
4. Copy the address from the status window and open it in your browser.
   Leave that window open. OK or Cancel stops only that wiki.
   Open the start file again to share another wiki alongside it.

You do not need to type terminal commands. A terminal window may remain
behind the dialogs; you can leave it there while using the helper.

Install Node.js and Tailscale on the computer first, using the links above.
An ordinary HTML wiki needs preparation before sharing. See “First setup”
in the wiki's ForgeShare guide and get help if needed. Keep the original.

If Mac says Apple cannot check the file for malicious software, stop
testing. This is a distribution limitation of this test helper. Extracting
again or changing execution permissions does not resolve that security
check. Do not type commands or disable protections. Apple's explanation:
https://support.apple.com/en-us/102445

Invitees need Tailscale. Restrict access to the intended wiki before
inviting anyone; see the guide. Keep backups and avoid editing the same
article simultaneously.
