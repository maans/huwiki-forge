# Sikkerhedsprincipper

- Den offentlige Forge og de byggede wikier indeholder aldrig GitHub-tokens eller private nøgler.
- Publisher er ikke implementeret. Når den kommer, bruges begrænsede, kortvarige skriveadgange uden lagring i tiddlere eller HTML.
- Kode fra plugins og eksterne kilder må behandles som kørbar kode med samme tillid som hosten.
- Første assembler-prototype tillader kun same-origin komponenter fra Edition-manifesterne.
- GitHub Pages kan ikke i sig selv modtage Talkback-beskeder; det kræver en senere backend.
- Browserens CORS-regler omgås ikke af projektet.
