# Distribution og selvhosting

- **Fork:** Kopi med Git-historik og mulighed for opdatering fra originalen.
- **Use this template:** Uafhængigt repository, efter ejeren har slået template-flaget til.
- **Download ZIP:** Kildekoden uden Git-historik.
- **Forge Edition:** Senere selvstændig TiddlyWiki med Forge-værktøjerne — ikke automatisk det samme som hele GitHub-repositoryet.

Relative filstier i manifests gør distribution fra en fork mulig. GitHub Pages skal aktiveres særskilt i forkens eget repository. Versionspolitik, licensvalg og en endelig TiddlyWiki-baseret launcher er stadig åbne udviklingsopgaver.
